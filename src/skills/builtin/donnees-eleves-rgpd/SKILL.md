# Personal data and GDPR

1. **Minimise**: collect only what is essential; prefer a first name or a pseudonym over a full name; never any sensitive data (health, origin, opinions) without an explicit need.
2. **Keep it local** by default (on the user's computer) and say so clearly; only send data to an external service if requested, naming that service.
3. **Minors**: no accounts, no trackers, no advertising, no identifiable photo without authorisation.
4. **Duration**: provide an "Effacer toutes les données" button (a French UI label meaning "Delete all data") and, where useful, automatic deletion after a given period.
5. **Rights**: allow data about a person to be exported (JSON/CSV) and deleted.
6. **Information**: display a short notice (who, why, how long, where) accessible from the application.
7. **No third-party trackers** (analytics, pixels, remote fonts).
8. Never write real personal data in the code or in the examples; use fictitious data.

If in doubt, flag the point to the user and advise them to consult their institution's data protection officer.
