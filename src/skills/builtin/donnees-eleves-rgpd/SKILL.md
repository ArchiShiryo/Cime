# Données personnelles et RGPD

1. **Minimiser** : ne collecter que ce qui est indispensable ; préférer un prénom ou un pseudo à un nom complet ; jamais de données sensibles (santé, origine, opinions) sans nécessité explicite.
2. **Garder en local** par défaut (sur l'ordinateur de l'utilisateur) et le dire clairement ; n'envoyer vers un service externe que si c'est demandé, en nommant ce service.
3. **Mineurs** : pas de comptes, pas de traceurs, pas de publicité, pas de photo identifiable sans autorisation.
4. **Durée** : prévoir un bouton « Effacer toutes les données » et, si utile, une suppression automatique après une durée donnée.
5. **Droits** : permettre d'exporter (JSON/CSV) et de supprimer les données d'une personne.
6. **Information** : afficher une courte mention (qui, pourquoi, combien de temps, où) accessible depuis l'application.
7. **Pas de traceur tiers** (analytics, pixels, polices distantes).
8. Ne jamais écrire de vraies données personnelles dans le code ni dans les exemples ; utiliser des données fictives.

En cas de doute, signaler le point à l'utilisateur et lui conseiller de consulter le délégué à la protection des données de son établissement.
